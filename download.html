Installation

Up and Running in Minutes

Four steps from download to a running macro

1

Download the archive

Hit any download button on this page and save Natro.Macro.Pro.v1.2.1.rar somewhere you can find it.

2

Extract it

Right-click the archive and choose Extract. Windows opens ZIP natively — for a RAR, use 7-Zip or WinRAR. Extract to a folder you own, not Program Files.

3

Run the setup wizard

Launch START.bat. The first-run wizard walks you through hive slot, field selection, and your gathering preferences.

4

Start the macro

Open Bee Swarm Simulator, then trigger the macro with your hotkey. It takes over from there — leave the game window focused.

Requirements

What You Need

Keep these in order and the macro runs smoothly

✓

Windows 7, 8, 10, or 11. 64-bit recommended. AutoHotkey ships inside the package — no separate install.

✓

Roblox installed. An active account with Bee Swarm Simulator unlocked and the game running without lag.

✓

A stable connection. The macro reads game state constantly, so packet loss shows up as misfires.

✓

Extraction tool. 7-Zip or WinRAR for the RAR archive, plus a few hundred MB of free disk space.

✓

Admin rights. Needed once, so the macro can send keystrokes to the game window.

✓

Game window focused. Run Roblox windowed or borderless — the macro needs it foregrounded while active.
